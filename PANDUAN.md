# Panduan: pasang & uji di Chrome Android

## Pasang di GitHub Pages (gratis, tanpa komputer)
1. Chrome → github.com → masuk / daftar.
2. Tombol **+** → **New repository** → nama `rytech-film` → **Public** → centang **Add a README** → **Create repository**.
3. **Add file → Upload files** → pilih `index.html` → **Commit changes**.
4. **Settings → Pages** → Branch: `main`, folder `/ (root)` → **Save**. Tunggu 1–2 menit.
5. Buka `https://USERNAME-ANDA.github.io/rytech-film/` di Chrome Android.

## Uji
1. Tunggu tulisan "Siap. Tekan Export MP4." (pratinjau berjalan sendiri).
2. Pilih **720p**, biarkan Suara tercentang, tekan **Export MP4**. Jaga layar menyala.
3. Setelah selesai, baca daftar centang (✓/✗), putar videonya, tekan **Unduh MP4**.
4. Buka file hasil unduhan di Galeri/Files dan putar di sana. Tekan ✅ atau ❌.
5. Buka **Laporan diagnostik → Salin laporan**, tempel ke chat.
6. Jika 720p berhasil, ulangi dengan **1080p**.
